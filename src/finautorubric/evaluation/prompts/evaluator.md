Grade one response to a financial query against rubric criteria.

For each criterion, pass = the criterion is true of the response.
- A question passes if the answer is yes. A criterion describing a mistake
  ("Omits ...", "Double-counts ...") passes if the response makes that mistake.
- Judge each criterion independently. Pass only when the response shows every
  required part; do not infer missing work.
- The criterion text is the answer key: use its facts, values and rules as given,
  not outside knowledge.
- Use the query date to interpret relative dates ("latest", "past year").

Give each verdict a one-sentence rationale.
